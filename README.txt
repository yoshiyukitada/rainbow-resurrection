Put these seven image files in the SAME folder:

Then upload all 10 files to a NEW GitHub repository and enable GitHub Pages:
Settings > Pages > Deploy from a branch > main > /(root).

Music:
Uses the YouTube IFrame Player API with video ID 5EyMNU8gxZs.
The embedded YouTube player is intentionally visible (200x200) and is controlled
with playVideo()/pauseVideo(). The browser may require the first interaction
to be a direct user gesture. If the video owner disables embedding, playback
will not work; the code displays an error status.

Controls:
- Press and drag on the artwork: objects swirl and the YouTube video plays.
- Release: video pauses.
- cat emits a rainbow beam toward the touch point; being hit causes a game-over state.
- Touch herin (angel) to revive.

This is a starter implementation. Test it with your own image assets after upload.
